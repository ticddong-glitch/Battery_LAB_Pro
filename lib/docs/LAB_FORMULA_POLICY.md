## Calculator Policy

Every calculator supports two modes.

1. Calculate Mode

The application calculates the result automatically.

2. Manual Mode (Skip)

Users may skip the calculation and enter the result manually.

Manual values are treated exactly the same as calculated values.

The UI must clearly indicate whether a value was

- Calculated
- Manually entered
